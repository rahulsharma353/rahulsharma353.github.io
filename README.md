# PM in the Loop

Source for the PM in the Loop site, built with GitHub Pages (Jekyll).

## Add a new essay

1. Create a file in `_posts/` named `YYYY-MM-DD-short-title.md`.
2. Start it with front matter:

   ```
   ---
   layout: post
   title: "Your essay title"
   pillar: Agent skills for PM work
   excerpt_text: "One or two sentences for the home page card."
   ---
   ```

3. Write the essay in Markdown below the front matter and commit. GitHub Pages rebuilds the site in a minute or two.
